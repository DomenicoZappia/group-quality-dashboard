Come leggere questi numeri

Verde = mediana entro il target - Rosso = mediana oltre il target. La mediana è più robusta della media perché il tempo di risposta varia molto da claim a claim. Stato verificato dai file nella cartella Master database: "Vuoto" significa che il file esiste ma non contiene ancora righe dati utili. I dati che alimentano la dashboard sono quelli caricati manualmente nella tabella sopra; questi master database servono invece come supporto per arricchire, correggere e standardizzare le informazioni.

Come aggiornare i dati

  1. Esporta il file aggiornato dalla lista, dal sistema di origine o da Power BI.
  2. Salva il file nella repository dati del sito, mantenendo il nome previsto nella tabella di import.
  3. Usa il pulsante Upload nella riga del dataset corrispondente ogni volta che hai una nuova estrazione: il sito legge il file, normalizza le colonne e ricalcola KPI, grafici e tabelle.
  4. Puoi ripetere l'upload più volte nello stesso giorno: resta valido l'ultimo file caricato e la tabella registra ora e nome file.
  5. I master database restano file di supporto: servono per arricchire codici prodotto, clienti, fornitori, classificazioni e regole, ma non sostituiscono i dataset operativi.

Nota: l'obiettivo è aggiornare direttamente dal sito. I dataset operativi caricati manualmente alimentano la dashboard; i master database migliorano normalizzazione, filtri e confrontabilità dei KPI.
